# Olá, eu sou o Igor

Estudante de Análise e Desenvolvimento de Sistemas, estudando desenvolvimento backend com Java e Spring Boot. Também tenho projetos de estudo em Python e C#.

## Projetos em destaque

- [Controle de despesas pessoais](https://github.com/Azt1/controle-despesas-java): API em Java e Spring Boot para cadastrar receitas e despesas, filtrar lançamentos e consultar o resumo mensal. Tem testes com JUnit; os dados ainda ficam em memória.
- [Webhook Dispatcher](https://github.com/Azt1/webhook-dispatcher): fila de eventos em Python e SQLite para enviar dados a webhooks, registrar os resultados e tentar novamente quando há falhas temporárias.
- [AI Document Processor](https://github.com/Azt1/ai-document-processor): aplicação em Python e FastAPI para analisar textos e PDFs, identificar informações e consultar o histórico pela interface web. A análise atual usa regras e padrões.
